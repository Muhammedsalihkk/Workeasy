#  Workeasy

**Workeasy** is a SaaS-based productivity and company management platform designed for startups and growing businesses.  
It helps organizations manage employee data, automate workflows, and analyze productivity using a scalable **MERN + Microservices** architecture enhanced with **TypeScript**, **Docker**, and **AI-powered face recognition**.

---

##  Tech Stack

###  Frontend
- React.js (TypeScript)
- Tailwind CSS / ShadCN UI
- Redux Toolkit / Context API

###  Backend
- Node.js + Express.js
- TypeScript
- MongoDB (NoSQL)
- RESTful APIs + Microservices
- JWT Authentication / OAuth 2.0

###  AI Module
- Python (Flask / FastAPI)
- Face Recognition & Computer Vision (OpenCV, dlib, face_recognition)

###  DevOps / Deployment
- Docker & Docker Compose
- Nginx Reverse Proxy
- GitHub Actions for CI/CD
- Cloud Deployment (Render / Railway / AWS / Azure)

---

##  Features

✅ SaaS-based multi-tenant company management  
✅ User authentication & access control  
✅ Employee record management  
✅ Task assignment & productivity tracking  
✅ AI-powered facial recognition login system  
✅ Modular microservices architecture  
✅ Real-time analytics dashboard  
✅ Fully containerized setup using Docker  
✅ Scalable, cloud-ready architecture
